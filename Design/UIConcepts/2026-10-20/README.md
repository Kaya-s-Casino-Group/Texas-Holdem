# BattleDemo UI · 2026-10-20

当前实装采用普通矩形框：深色底、细边框、Noto Sans CJK 正常字体。主界面、悬停牌库速览、完整牌库总览及卡牌提示统一使用这一样式。

旧装饰 UI 贴图、概念图及参考截图已清理。当前实机截图保存在 `Implemented-Plain/`：

- `Opening.png`：开局弃牌阶段。
- `Action.png`：出牌阶段与牌型计分。
- `Deck-Summary.png`：居中的悬停牌库速览。
- `Deck-Overview.png`：完整牌库总览。

## 实装约束

- 唯一场景为 `Assets/Scenes/BattleDemo.unity`，保留现有角色和怪物面片、背景及 Classic CardAtlas。
- 弃牌阶段只显示阶段及选牌数量，不显示牌型计分；出牌阶段选择上限读取规则层。
- 最高牌型用于计分，兼容牌型直接读取规则层 `PreviewHandFacts`，显示在牌型下方；Unity 不重新计算伤害。
- 玩家状态位于玩家血量旁，怪物血量及状态位于头顶；没有状态时隐藏状态区域。
- 斜面板只展示「意图」，右侧只展示遗物。
- 牌库速览居中并覆盖战斗 HUD，牌库总览保持最高层级。
- 画面上的背景选择按钮已移除，保留三套背景资源及编辑器切换能力。

## 验证记录

- 32 项 Unity EditMode 针对性测试通过：场景 XML/流程 26 项、候选牌型显示 4 项、状态与遗物投影 2 项。
- 同花顺与葫芦使用最新本地规则，预览和实际扣血一致，兼容状态效果生效；预览不改动权威状态。
- BattleDemo 开局、出牌阶段和两个牌库面板已进行 Play 模式检查，无运行错误。
