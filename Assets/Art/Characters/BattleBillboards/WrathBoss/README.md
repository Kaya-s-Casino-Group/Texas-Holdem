`WrathBossArtwork.asset` 保存坐标、材质及顺序。`WrathBossArtworkLayout` 将同一 PSD 像素比例映射到相机安全区，保留六个独立逻辑 Actor、完整 UV、受击/灰烬/复原路径。预警红光仅在显示快照的 `wrath.warning` 生效时出现；断手打断、重新开局和战斗结束时关闭。

点击按源 PNG 的 Alpha 过滤，透明像素穿透到后方图层，重叠区域按 PSD 前后顺序选择。角色贴图开启 CPU 可读以进行 Alpha 检测，GPU 导入上限为 2048；原始 PNG 未缩小或拼平。

编辑器菜单：`工具/卡牌战斗/暴怒美术/按 PSD 布局接入两个场景` 更新独立 `WrathBossDemo` 与七站 `SingleChapterAdventure`。同目录菜单提供 EditMode、PlayMode 验证。独立 Boss 的说明面板移至左上，为右侧拼装角色留出空间。

主场景 `Assets/Scenes/SingleChapterAdventure.unity` 的 Boss 占位高度从视口 0.76 提高到 1.08（再次放大约 42%），布局区域为 (0.22, -0.08, 0.82, 1.08)，下半身允许被底部卡牌 UI 遮挡，五手仍严格共用原 PSD 的像素比例。冒险里的本体血条固定在相机安全区顶部 90% 处，宽度为安全区 40%，只展示本体生命；护盾、状态和意图继续沿用已有敌人图标。五只手沿用小怪 HUD，按手掌位置放置，UI 保持放大前的紧凑尺寸（原 60% 比例再补偿 0.76 / 1.08），生命数字补偿字号，断手倒计时仍跟随同一手部对象。所有手掌 UI 锚点可在美术定义的 HudPixel 中调整，不改变 PNG 或 PSD 的拼装坐标。

2026-10-22 验证：Unity 脚本编译无错误、无警告；前一版表现层 EditMode 678/678 通过；再次放大后七站 Boss PlayMode 1/1 通过，包含顶部血条位置、手部 UI 尺寸、五手断裂、菜单恢复及原位再生。原始结果与截图在 `Library/WrathBossArtwork/`（运行产物，不纳入 Git）。初次接入时独立 Boss/普通出牌 PlayMode 另有 4 项通过。
