## 内容适配框（2026-10-22）

使用内置 imagegen，参考原始 `Button.png` 和 `Panel.png` 生成：
- `Resources/DeskUI/ContentButton.png`：金棕双线边、暗红底、小叶形角饰，无图标隔断，供文字按钮使用。

这两种框使用九宫格，角饰固定尺寸，只有平直边和低对比底色延展；背景、图标、Logo 与手牌托盘仍保持原图比例。文字使用独立留白区域，不跨越边框。替换奖励列表使用裁切滚动区域，避免道具多时覆盖底部操作。

生成提示词要点：以原始两张框为风格参考，输出可直接用于游戏的正视 UI PNG，古金/青铜双线边框、低饱和暗红黑底、小型叶形角饰仅放四角；去掉中间宝石、尖刺、图标分隔和示例文字；保持宽阔内容区，边线平直，适合九宫格。按钮约 5:1，面板约 3:2，透明背景。实际原始输出保留在 Codex generated_images 中，工程保存无损副本。
