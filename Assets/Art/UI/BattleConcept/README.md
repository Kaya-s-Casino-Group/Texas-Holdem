# 局内 UI 素材与布局

- `Resources/BattleConcept`：运行时加载的透明 PNG。补充的 4 张面板和 9 个状态图标由内置 ImageGen 生成，提示词与源图记录在 `GENERATED_SOURCES.json`。
- 玩家头像来自项目原始 IDLE 立绘；遗物及手牌继续使用项目原图。
- `DeskBattleLayout`：1856 × 850 参考画布，右侧两列遗物，底部手牌与居中效果预览，纯图标牌堆及垃圾桶。
- `BattleDemoEnemyWorldHud`：意图、血量、状态依次放在怪物头顶，保留实际战斗数值与悬浮信息。
- UI 图片使用等比容纳和统一缩放。新素材只在 Sprite 导入时选择有效透明边界，不重采样、不使用九宫格拉伸。
- `ConceptHealthBar`：玩家绿色、小怪红色、Boss 深红色；血条的边框、轨道和填充分层，填充采用水平裁切。
- 血条框保留原始画布及其填充坐标，不能与其他素材一样裁透明边。
- 场景背景、材质、灯光和色彩处理不属于本 UI 设置。

Unity 菜单 `工具/局内UI/应用已确认概念布局` 导入素材并保存布局。隔离预览关闭自动存档；`截图` 只截取游戏画面；`清理隔离预览` 返回正式场景并删除临时副本。

`整理对齐并清理旧元素` 统一底部中线、牌堆角标尺寸、排序按钮与外框的位置，居中遗物网格，删除旧装饰和停用的计分预览；仍被逻辑引用的隐藏标签归入 `Data Bindings`。

本轮按用户要求没有运行测试。
