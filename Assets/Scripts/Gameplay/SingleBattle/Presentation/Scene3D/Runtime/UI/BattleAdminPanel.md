# Unity 当前对局修改器

游戏获得焦点时按 **F5** 打开对局修改器窗口。旧场景的「对局修改器」按钮自动隐藏；窗口已打开时再次按 F5 不会重读或丢弃草稿，关闭仍使用窗口内的「关闭（丢弃草稿）」按钮。编辑器也可通过 `Tools > BattleDemo > Open Runtime Administrator` 打开。它使用当前 Unity 对局，不连接 H5 会话，不写回 XML。

- 血量页：编辑所有玩家和敌人的当前生命、生命上限、护盾；玩家金币支持非负 64 位整数。
- 遗物页：从当前引擎的内容目录添加遗物，移除或调整结算顺序；可编辑等级、剩余次数、成长、冷却和本回合使用次数。已有遗物保留实例及内部记忆，次数留空表示沿用。
- 手牌、牌库、弃牌堆：选择牌面，新增、复制、移除、移动、排序，切换不可出牌、不计分、增强、镀膜和禁用标记。牌库第 1 张最先摸到；移入牌库放到牌顶。
- 「预览修改」只校验候选状态；「应用修改」经 `BattleSessionPlayback.ApplyAdmin` 原子提交并同步手牌、角色、HUD 和候选预览。失败不留下部分修改。
- 面板草稿绑定会话与版本。对局推进或重开后必须重新读取，关闭会丢弃草稿。牌区操作仅影响本场对局。
- 动画期间、非玩家决策阶段、终局不能应用。修改不消耗行动点或随机数，不执行普通伤害、复活、掉落触发；生命设为 0 可直接改变胜负。

相关验证：`Poker.SingleBattle.Tests.BattleAdminPanelTests`。面板使用已有字体和 uGUI，不增加相机或美术资源。
