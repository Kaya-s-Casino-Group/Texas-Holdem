# 卡牌图集工具

Unity 菜单：**Tools → Cards → Atlas Builder**。

窗口可调整大小，最小 360×320。宽窗口使用左右布局，宽度小于 720 时切换为「卡牌 / 图集预览 / 配置与替换」分页，缩略图列数按可用宽度重新排列。统计、配置和卡牌列表可滚动。图集预览默认「适应窗口」，随窗口尺寸自动缩放；支持 1%–400% 手动缩放、100% 按钮，以及 Ctrl / Cmd + 滚轮围绕鼠标位置缩放。预览缩放不改变导出尺寸。

1. 选择项目内或外部的 PNG/JPG 目录，点击「扫描 / 刷新」。可勾选「含子目录」。
2. 「卡牌」页按黑桃、红桃、梅花、方块、大小王 / 卡背逐一列出标准位置。完整牌组是 **52 张 A–K + 两张 Joker + 一张卡背，共 55 张**。
3. 红色空位表示缺失；重复牌在同一牌位全部展开、标注「重复 n/m」，悬停文件名查看完整路径。额外牌 / 未识别图片在下方单独列出。「仅看问题牌」筛选缺失、重复、额外牌和图片尺寸 / 比例异常。
4. 顶部同时校验目录全部图片与当前勾选图片。「可组成完整牌组」表示 55 个标准位置都有文件，但还有重复或额外牌；「完整标准牌组」表示每个位置恰好一张且无额外牌。
5. 每张图片都可独立勾选，包括重复和额外牌。支持全选、全不选。「每牌选一张」选择各标准牌位在当前图集顺序中的第一张，取消其他重复和额外牌。**缺牌不阻止导出部分牌组**。
6. 点击缩略图，在左侧替换单牌图片、编辑图集 ID 或调整图集顺序。命名识别按原文件名确定，替换图片或编辑 ID 不改变对应牌位。替换不修改源文件。
7. 设置单牌尺寸、列数、扩展留边、比例处理、缩图算法和纹理采样。「图集预览」实时显示牌位标识、索引与线框，修改尺寸 / 列数 / 留边 / 排列 / 勾选后立即更新，无需生成图片或点击刷新。保存 / 加载配置可保留路径、顺序、勾选、替换关系、ID 和生成参数。

默认图集排列为 **卡背 → 黑桃 A–K → 红桃 A–K → 梅花 A–K → 方块 A–K → 大王 → 小王 → 额外牌**，从左至右、从上至下填入网格。勾选的卡背位于左上角、索引 0；若未勾选卡背，不预留空位。同牌重复图片连续排列，额外牌放最后，两者保留配置中的相对顺序。

「图集排列」可切换为「手动顺序」，使用配置中的原有顺序。点击前移 / 后移会先按当前默认排列展开全部图片，再切换到手动顺序。缩略图的 `#n` 与实际图集一致，从 0 开始；取消勾选或切换排列会更新索引和 UV。扫描保留已有文件顺序、替换和勾选，新文件追加；默认花色排序会自动把新牌放到对应花色和牌值位置。

## 命名识别

| 类型 | 标准文件名 | 支持的别名 |
| --- | --- | --- |
| 黑桃 | `spades_a`、`spades_02` … `spades_10`、`spades_j/q/k` | `spade`、`黑桃` |
| 红桃 | `hearts_a`、`hearts_02` … `hearts_10`、`hearts_j/q/k` | `heart`、`红桃` |
| 梅花 | `clubs_a`、`clubs_02` … `clubs_10`、`clubs_j/q/k` | `club`、`梅花` |
| 方块 | `diamonds_a`、`diamonds_02` … `diamonds_10`、`diamonds_j/q/k` | `diamond`、`方块` |
| 大王 | `joker_big` | `big_joker`、`大王` |
| 小王 | `joker_small` | `small_joker`、`小王` |
| 卡背 | `card_back` | `back`、`卡背` |

忽略目录和大小写。花色与牌值可以交换顺序，支持空格、下划线、连字符或不加分隔符。`1/01` 等同 A，`11/12/13` 等同 J/Q/K，2–9 可带前导零。

`_v2`、`_copy` / `_copy2`、`_alt` / `_alt2`、`_variant2`、`_副本2` 或 ` (2)` 等后缀作为同牌变体，计入重复。例如 `one/spades_a.png`、`two/spade_01.jpg` 与 `spades_a_v2.png` 都对应黑桃 A。其他不符合规则的名称列入额外牌，不猜测其身份。

## 尺寸 / 比例校验

左侧可设置原图标准尺寸、标准宽高比与比例容差，随配置资产保存。默认检查 **1024×1536、2:3、比例容差 0.5%**。关闭「校验原图尺寸」可允许同一比例的不同分辨率图片。

校验读取原始 PNG/JPG 文件，不使用 Unity 已缩小的导入尺寸。原图和替换图片分别检查；每张缩略图显示实际采样图片的尺寸和异常状态，悬停状态可查看原图 / 替换图详情。卡牌页分别统计全部图片和已勾选图片中的尺寸异常、比例异常、需放大与无法读取数量。缓存只保留尺寸，刷新扫描或窗口重新获得焦点后重新检查文件变化。

尺寸比较要求宽高都与标准一致；比例容差按实际宽高比相对标准宽高比的偏差计算。0.5% 可接受 171×256 的像素取整，设为 0 时要求精确比例。图片小于图集单牌的实际重采样需求时标注「需要放大」，按单牌尺寸与整组 Fit / Fill / Stretch 变换后的最终像素需求判断。

图集单牌宽高也与标准比例校验。例如 128×256 不符合 2:3，会提示放入牌位时拉伸；整组比例处理不用于修正单张牌的比例。尺寸 / 比例不符只提示，不限制自选图集；无法读取实际采样图片仍会使构建失败。

## 导出与采样

图集预览只计算布局，不读取卡牌像素、不分配图集纹理。内框是单牌范围，外框是扩展留边；显示 `#索引` 与花色 / 牌值，卡背和大小王使用文字标识。点击线框可选中对应卡牌，悬停可查看 ID、路径、像素矩形与 UV。未勾选任何牌或参数无效时显示提示。实际图片仅在「导出图集」时生成，导出与线框共用布局计算。

默认单牌逻辑尺寸 128×192，8 列、4 像素扩展留边、图集边长 2048，Point / 无压缩 / 无 mipmap。FourBeasts 55 张牌生成 2048×2048 图集。读取原始图片文件，不受单牌 171×256 的 Unity 导入尺寸或 Read/Write 设置限制。

- `.png`：图集。
- `.json`：每张已勾选图片的 ID、索引、像素矩形、UV、布局与采样配置。
- `.asset`：项目内导出时生成的 `CardAtlasData`，引用贴图并保存牌位 UV 数据。

工具不包含 Shader，也不创建材质。之前的示例 Shader 与材质已移到 `ArtSource/Cards/DeferredRendering/` 存档。

项目外只导出 PNG 与 JSON。项目内自动设置 Filter、Wrap、sRGB、Mipmap、Compression、Aniso，关闭 NPOT 缩放。重复导出保留 PNG 和数据资产 GUID。导出目录须在源卡牌目录以外。

UV 以左下角为原点，`uv.xy` 是偏移，`uv.zw` 是缩放，不包含扩展留边。UV 保存完整牌位的连续坐标；`pixels` 记录落在牌位内的像素中心范围。Fill 被裁切的牌带有 `clipped=true`、`visiblePixels` 为图集内可见像素范围，完整 UV 可以超出 [0,1]；完全移出图集的牌仍保留索引且可见宽或高为 0。`CardAtlasData.TryGetCard(id, out region)` 可按图集 ID 查找。额外牌也使用各自的图集 ID，导出校验 ID 非空且唯一。

图集始终为正方形。「最大图集尺寸」可输入任意整数作为边长；关闭「图集尺寸取 2 次幂」时严格使用该整数（例如 1500×1500），开启时向上取二次幂（1500 → 2048×2048）。最终边长不得超过设备支持尺寸与 8192 两者中的较小值。改变列数、牌数和单牌逻辑尺寸只改变网格与缩放，不改变指定的图集边长。

「比例处理」作用于**排列好的整个牌组网格**（含扩展留边），从左上角开始：

- Fit：整组等比缩放，完整放入图集，剩余空间透明。
- Fill：整组等比缩放并填满图集，右侧或底部超出部分裁切，可能裁掉整张牌。预览标出裁切张数并按图集边界裁切线框。
- Stretch：分别缩放整组的宽高，使网格填满正方形，牌面可能变形。

最后一行未使用的牌位保持透明；Fill / Stretch 填满的是网格外接矩形。单牌宽高和留边是网格缩放前的逻辑尺寸，最终像素尺寸取决于整组变换。生成时直接从原始图片一次重采样到最终牌位，避免先缩小再放大的细节损失。

Point 是纹理采样，Nearest 是生成时的重采样算法，两者独立。像素牌建议使用 Point / Nearest 并关闭 mipmap。

验证：`CardArt.Tests` 覆盖命名别名、缺失 / 重复 / 额外牌、目录和勾选校验、替换身份、原文件尺寸、比例容差、替换图尺寸、文件变化与解码失败、放大判断、整套 FourBeasts、打包方向与留边、导入设置、GUID 保留和不导出材质。

## 卡牌 Prefab 导出

窗口新增 **Prefab 导出** 页签，选择图集 Data / Shader / Mesh 即可导出通用 Card Prefab 和共享材质；可通过 `Tools/Cards/Prefab Exporter` 直接打开。默认牌面、卡背、Shader 接口和 Mesh 兼容性会在导出前校验，详细约定见 `Tools/CardRendering.md`。
