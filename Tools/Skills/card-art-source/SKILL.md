# 原始卡牌资产生成

生成可直接供项目 Atlas Builder 扫描的单张原始卡牌。开始前读取 [references/contract.md](references/contract.md)。输入契约固定；美术风格由本次用户要求、会话中明确选定的风格或用户指定参考决定。

## 交付边界

```text
<交付目录>/
  originals/
    card_back.png
    spades_a.png
    ...
    joker_small.png
  cards.json
```

仅交付用户要求的原始 PNG 与这份配置文本。配置记录原图规范、实际牌组清单和交接采样要求。它不是 Unity Recipe 或 Atlas Manifest，工具不会自动加载它。

Atlas Builder 已负责扫描、牌位识别、自动排序、缩放、扩展留边及 UV 计算。本 skill 不生成 atlas、拼图、缩略图、Unity `.asset`、`.meta`、材质、Prefab、Shader、场景或验证报告。不要把图集留边画进单牌。最终答复简短链接交付物。

默认在项目 `ArtSource/Cards/<牌组名>/` 下创建新交付目录；项目外使用用户指定目录。中间生成图和检查缩略图放临时目录，交付目录的 `originals/` 只保留最终标准命名 PNG。默认不覆盖现有游戏资产。

## 确定范围与视觉基准

- 按用户要求生成全套、指定子集或替换单牌；不把单牌请求扩展成 55 张。全套为 52 张 A–K、大小 Joker 和一张卡背。风格信息不足且上下文无法判断时询问；不自动选取项目中某个牌组作为风格默认值。
- 用户要求延续某个牌组时，从用户指定的目录、图片或明确选定的牌组中查看相关原图。替换单牌同时查看原牌和邻近牌；新风格请求直接采用所要求的风格，不从其他项目牌组引入动物、纸色、像素笔触或构图。
- 按选定风格确定底色、边框、笔触、角标、花色配色、主体比例和安全边距。同套保持这些因素一致，不预设主题、角色物种、纸张纹理或色盘。整套先完成一个有代表性的牌面，检查缩小后的可读性，再扩展到其余牌；检查预览不进入交付目录。

## 生成与检查

1. 使用可用的图像生成工具生成完整、正视、竖向的单张卡牌；若环境提供 imagegen skill，生成时读取并遵守它。新绘图和视觉修改走图像生成/编辑工具，保留参考图；最终一文件一牌，不让模型直接生成整套 atlas 或多牌拼图。
2. 最终原图必须为 **1024×1536 PNG、2:3、正常朝上**。模型结果若尺寸不符，先修正生成；必要的格式/采样转换保持比例并使用 Nearest，禁止把横图拉伸为竖牌、靠模糊插值掩盖错误或把低分辨率牌冒充原始图。
3. 核对每张牌角标的牌值和花色、数字牌中央大花色的数量、边框完整性与方向。右下角标为左上角标的 180° 旋转。A、J、Q、K 的角标使用字母；2–10 使用数字。卡背没有牌值角标。
4. 默认 J/Q/K 为精确 180° 像素对称；AI 声称“对称”不算验证。对称构建属于确定性资产加工：先生成适合双头旋转拼接的牌面，再将保留的半幅精确旋转复制至另一半。接缝位置与形状随本次构图确定，保持脸部、角标、边框与装饰完整；检查接缝质量和数组对称。只有用户明确选择非对称 J/Q/K 时才关闭这项检查。Joker 插图不要求对称，但对角角标需对应。
5. 不把运行时镭射、火漆、红叉、选中 tint、光照和阴影烘焙进基础牌面。需要纸张/油墨风格时沿用美术基准。
6. 使用标准文件名保存最终 PNG；原始画布不加采样留边、不翻转、不裁去边框。不将 Unity 缩小后的导入纹理作为原图。

## 校验与配置文本

运行随 skill 附带的 `scripts/validate_sources.py`。依赖 Python 3 与 Pillow；优先使用当前已有 Python 环境。校验不修改原图，只在全部通过后写 `cards.json`；错误只打印到终端。

全套示例（用实际 skill 路径替换 `<skill>`）：

```bash
python3 <skill>/scripts/validate_sources.py <交付目录>/originals \
  --manifest <交付目录>/cards.json --style "本次用户指定的风格与视觉基准"
```

子集示例，明确列出预期 ID，不能用“缺牌允许”掩盖漏生成：

```bash
python3 <skill>/scripts/validate_sources.py <交付目录>/originals \
  --ids spades_q hearts_k --manifest <交付目录>/cards.json --style "用户指定主题"
```

脚本检查标准命名、数量、缺牌/额外牌、PNG 实际格式、1024×1536、RGB/RGBA、全画布不透明、EXIF 朝向与 J/Q/K 像素对称。全画布不透明是当前基础纸牌的输入要求；透明覆盖层不属于本 skill。用户明确授权非对称 J/Q/K 时使用 `--allow-asymmetric-court` 并在配置中记录该例外。

脚本无法判定角标正确、花色数量、风格一致和缩小后的可读性；必须目视检查实际最终图及 Nearest 缩小的内部预览。修正不合格图后重新校验，全部通过再交付。不能把“脚本通过”写成所有美术检查均自动通过。
