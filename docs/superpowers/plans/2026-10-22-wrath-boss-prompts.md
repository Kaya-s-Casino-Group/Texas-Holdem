# 暴怒 Boss 提示与可玩交互补齐

> 执行：superpowers:subagent-driven-development。用户已授权完成当前可完成项目，图标采用占位，正式 UI、美术和动画后续接入。

**Goal:** 补齐截图中的文字提示、占位意图图标、Web 点击选敌，以及五手拒绝加攻和护盾的规则。

**Architecture:** 保留已确认的 Boss 权威状态及普通战斗语义。展示只消费状态和实际回放边界；瞬时提示不由刷新或预览重复触发。Web 与 Unity 使用独立展示适配，图标按明确动作身份映射；手的效果限制按 Boss 手身份隔离，复活后仍有效。

**Tech Stack:** 纯 C# / NUnit、Unity TMP/UI、H5 JavaScript/CSS、现有 HTTP 与浏览器回归。

## 已确认的展示约定

- 入场红字原文：`警告：每存活一只手，暴怒攻击力+5！！`；每场出现一次，并保留可查阅的机制提示。
- 大招警告原文：`警告：Boss有五只手臂，将释放大招！！`；仅权威预警生效时显示，断手取消或战斗结束后移除。保留释放轮与预测伤害辅助信息。
- 断手处显示血红色剩余轮数，死亡当轮为 8；每敌方阶段开始在对应位置冒字 `X个回合后再生`；再生后移除数字。数字和冒字使用规则查询结果，客户端不自行递减。
- 常规意图按 `strike`/`strike-2`、`guard`、`charge` 显示可替换的攻击、防御、蓄力占位符；不把 `GainBlock(0)` 当作护盾技能。大招保持独立，不插入八格普通意图。
- Web 可点击或键盘选择可选的存活敌人，和原下拉框绑定同一目标槽位；明确本体／饮血手／束缚手名字和选中态。群攻没有单体槽位时不伪造选敌；死亡手禁选。
- 五手禁止获得正向加攻／护盾；控制、毒、伤害、再生及本体免伤仍按现有规则。复活后限制不丢失，普通单位不受影响。
- Unity 补齐可编写的提示与目标位置绑定，使用占位图标和现有模型；实际 Unity Editor/PlayMode 验收若环境不可用必须明确记录。
